# Code of Conduct

## Our standard

QuickNest contributors should keep collaboration respectful, specific, and focused on improving the project.

Expected behavior includes:

- discussing ideas and code without attacking people;
- welcoming users with different experience levels;
- giving actionable technical feedback;
- respecting privacy and never requesting unnecessary launcher data;
- accepting maintainers' decisions about scope, safety, and compatibility.

Harassment, discriminatory language, threats, deliberate disclosure of private information, and sustained disruption are not acceptable.

## Scope

This standard applies to repository discussions, Issues, Pull Requests, reviews, and other spaces where someone represents the project.

## Reporting

For sensitive conduct or security-related reports, contact the maintainer privately through the repository's Security Advisory flow. Do not publish personal information in an Issue.

## Enforcement

Maintainers may edit or remove contributions, lock discussions, reject changes, or restrict participation when behavior conflicts with this standard. Enforcement decisions should be proportionate and documented privately when possible.
